Three steps to get started

  1. Prepare your repository

    Create a GitHub repository with a README and a token with Contents read/write access.

  2. Start the companion

    Open a terminal in the server folder.

    npm run setup
npm start
  3. Pair and solve

    Paste the pairing key here, connect, then reload LeetCode. New accepted submissions will enter your queue.

Repository, branch, and folder are configured by npm run setup. Changing destination never silently redirects older queued solutions.
